# 🎓 AI-LMS

A modern **AI-powered Learning Management System** built with the **MERN Stack**. It enables students to discover and purchase courses while allowing creators to manage and publish educational content. The platform integrates secure authentication, online payments, cloud storage, and AI to deliver a seamless learning experience.

## ✨ Features

- 🔐 JWT & Google Authentication (Firebase)
- 📚 Course Creation & Management
- 🎥 Video Lecture Support
- 💳 Razorpay Payment Integration
- ☁️ Cloudinary Image Uploads
- 🤖 AI Integration (Google Gemini)
- ⭐ Course Ratings & Reviews
- 📧 Forgot Password via Email
- 📱 Responsive UI

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Redux Toolkit  
**Backend:** Node.js, Express.js  
**Database:** MongoDB Atlas  
**Services:** Firebase, Cloudinary, Razorpay, Gemini API, Nodemailer

## 🚀 Getting Started

```bash
git clone https://github.com/Atharv0721/Internship-Project-LMS-Web.git
cd AI-LMS
```

Install dependencies:

```bash
cd backend && npm install
cd ../frontend && npm install
```

Run the project:

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
